## 🌟 Key Features

- **🏆 Verified Cohort Leaderboard**:
  - Deterministic scoring engine combining Milestone completion (M1: 100 pts, M2: 200 pts, M3: 300 pts), Skill Badges (50 pts each), and Profile Health validations.
  - Mandatory **Cohort Access Code Redemption Priority**: Only verified redeemed students are ranked on the official cohort podium.
  - Inscribed medal coins (`1`, `2`, `3`) for Gold, Silver, and Bronze champions.

- **🎨 Neomorphic Apple White-Mode Interface**:
  - Soft-UI tactile design system (`#F0F4F9` canvas, dual directional shadows, inset input wells, debossed control pills).
  - Responsive layout optimized for mobile smartphones, tablets, laptops, and ultra-wide desktops.

- **👤 Culturally-Aware Gender-Specific Student Avatars**:
  - Pure vector SVG illustrated avatars dynamically inferred from student names.
  - Distinct feminine hairstyles, accessories, and styling for female students; sharp modern haircuts and styling for male students.

- **🎯 Interactive Official Course Roadmap**:
  - 10-course Google Cloud syllabus mapping from Compute Basics, IAM Roles, and Pre-trained APIs to Generative AI in Agent Platform.

- **🏅 Achievements & Wall of Champions**:
  - Tiered swag milestone tracker (Tier 1: 5 Badges, Tier 2: 10 Badges + Milestone 3 swags).
  - Complete Google Cloud skill badge showcase.

- **🔒 Zero-Knowledge Privacy Architecture**:
  - Public interface exposes zero private student emails or access codes.
  - Administrative vault with master key authentication for cohort management and data imports.

## 💻 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18.0.0 or higher recommended)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation

```bash
# Clone the repository
git clone https://github.com/shaiksameer2431-maker/GDG-OC-NECN.git
cd GDG-OC-NECN/Frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be live at `http://localhost:5173`.

### Production Build

```bash
cd Frontend
npm run build
```

The production assets will be output to the `Frontend/dist` folder.
